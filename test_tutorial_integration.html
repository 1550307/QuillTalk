📖 Expected Behavior

For users with tutorial_completed = 0 AND tutorial_skipped = 0:
  1. User logs into QuillTalk (app.php)
  2. Page loads normally
  3. After 2 seconds, tutorial prompt appears in top-right
  4. User can click "Start Tour" or "Skip"
  5. Choice is saved to database
  6. Tutorial won't appear again
Important: ALL existing users have default values (0, 0) so they will see the tutorial on their next login!

🛠️ Troubleshooting

Tutorial doesn't appear

Check database status: SELECT tutorial_completed, tutorial_skipped FROM users WHERE id = YOUR_ID;

Reset if needed: UPDATE users SET tutorial_completed = 0, tutorial_skipped = 0 WHERE id = YOUR_ID;

Migration didn't run

Delete flag file: rm htdocs/uploads/.tutorial_schema_applied

Then reload any page to trigger migration

JavaScript errors

Open browser console (F12) and check for:

  • tutorialCompleted is not defined - Check app.php line ~11669
  • TutorialSystem is not defined - Check tutorial_system.js is loaded
  • Network errors - Check update_tutorial_status.php exists
